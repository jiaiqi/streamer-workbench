# 潮光留白

这一视觉哲学让信息像阳光下的潮水一样清晰，让装饰像远处的海岸一样存在。文字永远是最接近观者的层级，水彩、波浪和珊瑚在柔光中逐渐退后。这种空间深度必须来自耗时而精确的透明度调校，而非简单的白色遮盖。

色彩保留薄荷绿、浅水蓝与珊瑚色的活力，但所有鲜艳度都被调整到服务阅读的范围。两张画面的海洋色调应像同一天的不同潮位——第一页是薄荷绿的清晨浅滩，第二页是珊瑚粉的暖调午后，有变化但不跳脱。这种色彩一致性需要大师级的细致校正，使两页在直播画面中自然连续。

半透明区域不是卡片，而是一层薄雾。它没有明确边框，边缘通过极轻的模糊溶入背景，只在需要保护对比度的地方出现。每一块柔光的强度都需根据下方图像细节逐一微调，展现出顶尖匠人反复试印般的精准。

文字使用柔和的深青绿和中等字重，在保持手机屏幕可读性的同时，避免密集排列形成深色块。分类标识像水彩笔记，底色更透气，下划线更细，只提供节奏而不像可点击按钮。

本版采用「统一边距」网格：所有分类共享同一组左右边距，每行从左边距起、到右边距止均匀分布，栏间距由程序按栏内容精确计算。不同分类的最左列严格对齐在同一根隐形轴线上，所有字号、基线和留白都应呈现经过无数次打磨的专业完成度。

最终作品应像一本高级夏日画册中的曲目索引：清新、柔和、有空气感，但读取速度毫不牺牲。观者不会先看见界面组件，而会先看见歌名，之后才注意到潮水、贝壳与珊瑚的温柔氛围。这种先后关系是整套视觉中最需要精心维护的工艺。
