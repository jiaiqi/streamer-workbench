# 青提气泡

这一视觉哲学是一杯清晨的青提苏打：清新的第一印象来自颜色，精致的整体感来自克制。画面里没有多余的装饰，只有必要的气息。

底色是极浅的薄荷绿到白的渐变，像被阳光晒暖的气泡水。装饰被严格限制在三类：零星上浮的透明气泡、角落里的一小串青提、底边的一缕青草和小白花。它们只出现在边角，中央阅读区保持完全干净——清新的感觉来自色彩与留白，而不是堆砌元素。

两页是同一天的两个时刻：第一页是带露珠的清晨青提绿，第二页是微微转凉的午后薄荷水色，有变化但不跳脱。所有元素都保持水彩般的轻盈透明度，绝不抢过文字。

文字使用沉静的深松绿，中等字重，在手机屏幕上清晰易读。分类标签是一小枚透气的薄荷绿贴纸，无描边，下方一条细细的珊瑚色下划线——整套画面里唯一的暖色，像青提汽水里的那一颗小樱桃，只提供节奏和一点甜。

文字背后没有卡片，只有一层向四周消散的柔光，刚好托住对比度。观者先看见歌名，然后才感觉到气泡和青提的清新——这种先后关系，是这套视觉最需要维护的工艺。
