# 单 HTML → Astro 项目升级方案

> **前提**（已收敛）：
> - 部署集成 = **GitHub Pages docs/ 重生**（Astro 输出覆盖根 docs/，URL 不变）
> - Island 边界 = **动态主题轮播 island**（Hero 区做最大化交互，承担全部 JS）
> - 主题画廊资源 = **金标准 + webp 双轨**（14 张 PNG + 7 张 webp 缩略图）
> **目的**：把 `site/landing/index.html` 升级为可维护、可演进、可部署的 Astro 项目。

---

## 0. 决策摘要

| 维度 | 决策 |
|---|---|
| 框架 | **Astro 4 + Tailwind 3**（与原方案一致） |
| 部署 | Astro 构建产物输出到根 `docs/`（替代现在手动复制的 `docs/index.html`） |
| 路径 | `base: '/playlist-poster-generator/'`（保留 GitHub Pages 子路径） |
| Island 范围 | Hero 主题切换区为单个 client island，承担轮播/光晕/键盘交互；其余页面纯静态 |
| 图片资源 | `tests/golden/` 14 张金标准海报直接复用 + 构建期 sharp 生成 webp 缩略图 |
| 包管理 | `pnpm`（与 `tools/` 一致） |
| TypeScript | 严格模式，content collections 用于 themes.json |

## 2. Astro 配置关键点

### 2.1 astro.config.mjs

```js
import { defineConfig } from 'astro/config';
import tailwind from '@astrojs/tailwind';
import sitemap from '@astrojs/sitemap';

export default defineConfig({
  site: 'https://jiaiqi.github.io',
  base: '/playlist-poster-generator/',
  outDir: '../../docs',          // 直接输出到根 docs/，覆盖现有的 docs/index.html
  trailingSlash: 'never',
  build: { inlineStylesheets: 'auto' },
  integrations: [
    tailwind({ applyBaseStyles: true }),
    sitemap({ changefreq: 'monthly', priority: 0.8 }),
  ],
  vite: {
    build: {
      assetsInlineLimit: 1024,  // < 1KB inline，CSS/小图标
    },
  },
});
```

### 2.2 Tailwind theme

`tokens.css` 直接派生 design-tokens.json v2 的品牌色 + spotlight/glow 角色。Tailwind `@theme` 块做语义映射：

```css
@import "./tokens.css";

@theme {
  --color-primary: var(--primary);
  --color-primary-strong: var(--primary-strong);
  --color-spotlight: var(--spotlight);
  --color-bg: var(--bg);
  --font-serif: "Noto Serif SC","Source Han Serif SC",serif;
  --font-mono: "JetBrains Mono",ui-monospace,monospace;
}
```

### 2.3 防 FOUC（关键）

`<head>` 内的内联脚本读取 `localStorage.gp-landing-theme` 在解析 CSS 前设置 `data-brand/data-mode`，避免主题切换时的白屏闪烁。与设计文档 §5.5 同款。

## 3. Island 设计（最大化交互）

### 3.1 唯一 Island：HeroPosterDeck.tsx

`client:visible` 加载的 React 组件（用 `@astrojs/react`）。职责：

- 7 张主题 poster 3D 堆叠散开动画（CSS transform + JS 鼠标位置驱动）
- 每 3 秒自动轮播到下一主题，主题色同步注入 CSS 变量
- 键盘 ←/→ 切主题，↑/↓ 切页（1/2）
- 主题自身 `--primary` 临时覆盖回原值前短暂展示新主题色（300ms 过渡）
- 鼠标移动驱动聚光光晕位置（通过 `mousemove` 事件 + `transform: translate3d`）

体积预算：≤ 30kb JS gzipped（含 React 18 ~ 12kb）。

### 3.2 纯静态部分

- Nav：主题切换按钮调一次 localStorage.write 后页面 reload（不需要 island）
- Stats：`data-count` 属性 + 内联 `<script>`（约 500 字节）做 IntersectionObserver 计数
- 其他：纯 SSR HTML + CSS

## 4. 图片资源策略

### 4.1 assets 流向

```
tests/golden/海洋柔光-全屏p1.png       (金标准，1080×2400，~1.2MB)
        ↓ scripts/gen-posters.mjs
        ├── site/landing/public/posters/海洋柔光-1.webp     (宽 540，约 80KB)
        ├── site/landing/public/posters/海洋柔光-2.webp
        └── public/og-image.png                               (1200×630 hero 缩略)
```

脚本要点：
- 读 `themes/*/theme.json` 取 7 主题名
- 用 `sharp` 生成 540×960 webp（quality 80）+ 1080×1920 webp（quality 85）双尺寸
- 顺便输出 `og-image.png`（Hero poster 缩略 + 标题文字）
- 包 `prebuild` 钩子：`astro:build:before`，保证 `pnpm build` 前资源就绪

### 4.2 ThemeGallery 资源

7 主题卡片用 webp 缩略图（srcset 多尺寸），保留金标准 PNG 作为 `tests/golden/` 原始资源。两者双轨：
- webp → 站点显示
- PNG → 金标准测试对照

## 6. 部署流程

### 6.1 本地开发

```bash
cd site/landing
pnpm install
pnpm dev                       # http://localhost:4321
```

### 6.2 构建产物（GitHub Pages）

```bash
cd site/landing
pnpm build                     # 输出到 ../../docs/
git add ../../
git commit -m "feat(landing): Astro 工程化构建"
git push origin master
```

### 6.3 Vercel（可选，主推）

`vercel.json`（仓库根）：

```json
{
  "buildCommand": "cd site/landing && pnpm install && pnpm build",
  "outputDirectory": "site/landing/dist",
  "framework": "astro"
}
```

两平台共享 `dist/` 内容，URL 不同但产物相同。

### 6.4 现有 `docs/index.html` 迁移

第一次构建后手动 `docs/index.html` 被覆盖，git 会记录这次替换。无须特别处理。

## 9. 风险与回退

| 风险 | 对策 |
|---|---|
| Astro 构建产物路径与 GitHub Pages base 不匹配 | astro.config base 明确 `'/playlist-poster-generator/'`；构建后用 `npx serve docs/` 验证 |
| `tests/golden/` 文件名是中文，构建脚本需 rename | `gen-posters.mjs` 一次性映射表，不在站点运行时处理 |
| HeroPosterDeck.tsx 体积超预算 | 用 Preact 替代 React（~3kb）作为 island 框架 |
| 现有 docs/index.html 被覆盖丢失 | git 记录替换；可随时回滚到本次 commit 前 |
| GitHub Pages 静态托管不支持 SPA 路由 | 不需要，Astro 全静态 + 哈希链接 |
