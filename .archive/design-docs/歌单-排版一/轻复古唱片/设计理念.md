# 轻复古唱片

这一视觉哲学是一张放在奶油色桌面上的黑胶：复古的气息来自元素，新鲜的观感来自颜色。它是「轻」复古——有唱片、便签和纸飞机的怀旧轮廓，但没有做旧、没有暗沉，整个画面像午后阳光晒暖的牛奶。

色彩以暖奶油白为底，陶土红、奶橙、薄荷绿与驼色像一组低饱和的蜡笔：砖红的唱片环、奶橙的便签纸、薄荷绿的波浪带，彼此呼应而不喧哗。两页同色系，像同一张桌子从正面和侧面看去的两个角度，有变化但不跳脱。

可爱但不幼稚的关键，是复古元素的分寸：黑胶、便签、纸飞机都用圆润的插画风勾勒，线条干净、配色奶油，全部收在底部，中央阅读区完全干净。怀旧只是气质，阅读才是主角。

文字使用沉静的深可可棕，中等字重，与唱片的深棕盘面暗暗呼应，在奶油底上清晰易读。分类标签是一小枚奶橙半透的圆角贴纸，无描边，下方一条细细的陶土红下划线——像便签纸上的一道手划线，只提供节奏，不像可点击的按钮。

文字背后不是卡片，而是一层向四周消散的暖白柔光，刚好托住文字的对比度。观者先看见歌名，之后才注意到唱片与纸飞机的温柔怀旧——这种先后关系，是这套视觉最需要维护的工艺。
