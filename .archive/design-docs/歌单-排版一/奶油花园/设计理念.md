# 奶油花园

这一视觉哲学让歌单像别在奶油花园里的一页手账：可爱的气息来自花与星光，精致的气质来自克制。文字永远是画面里最清晰的层级，水彩花束、细线云朵和音符光点只在边缘轻声陪伴，绝不进入阅读区。

色彩以暖奶油白为底，第一页是蜜桃与杏粉的清晨，第二页是玫瑰与淡紫的午后——像同一座花园里光线转柔的两个时刻，有变化但不跳脱。所有鲜艳度都被压到服务阅读的范围内，金色的星星和音符只是零星点缀，像花园里不小心洒落的闪粉。

可爱但不幼稚的关键，是元素的手绘感与留白比例：花只开在底部和边角，云朵、弯月和彩虹退为边角的小点缀，小到像书签上的烫金图案。装饰一旦接近歌名，就必须退后。

文字使用沉静的深可可棕（第二页为深莓紫），中等字重，保证手机屏幕上的读取速度。分类标签像一枚小小的手账贴纸：蜜桃粉（第二页为玫瑰粉）的圆角底色，透气、无描边，下方一条细细的珊瑚色下划线只提供节奏，不像可点击的按钮。

文字背后不是卡片，而是一层晨雾。它没有边界，向四周自然消散，浓度刚好托住文字的对比度，又让下方的花枝若隐若现。观者先看见歌名，之后才注意到花、云与星光——这种先后关系，是这套视觉最需要维护的工艺。
