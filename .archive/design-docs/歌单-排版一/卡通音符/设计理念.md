# 卡通音符

这一视觉哲学是一支小小的乐队守在页面底部：可爱的角色负责让人微笑，干净的版面负责让人读歌。两者互不越界。

底色保持极简：第一页是奶白微薄荷的清晨，第二页是蜜桃奶霜的午后，像同一场小型演出的日场与晚场。色彩饱和度被压低到 pastel 范围，精致感来自统一的扁平插画风和细描边，而不是数量。

卡通元素是一支编制固定的乐队：微笑的音符小伙伴、头戴式耳机、黑胶唱片、木吉他、磁带、复古麦克风、随身听、小键盘。它们全部矮矮地守在底部边缘和边角，像站在舞台下沿——绝不长高、绝不进入阅读区、绝不压过任何一个歌名。顶部角落只允许漂浮两三个小音符，保持空气感。

文字是画面真正的主角：第一页深松绿、第二页深可可棕，中等字重，严格网格对齐。分类标签是透气的薄荷绿/蜜桃粉小贴纸，下方一条细细的珊瑚色下划线，是两页共有的节拍记号。

文字背后只有一层向四周消散的柔光，刚好托住对比度。观者先读完歌名，目光落到底部时才遇见那支小乐队——这种先后关系，是这套视觉最需要维护的工艺。
