# UI 探索预览

本目录保存早期 Apple 风格与 Liquid Glass 方向的可交互 HTML 探索稿，便于追溯视觉语言和交互尝试。

这些文件不是当前执行规格，也不代表已经实现的功能：

- 当前产品/UI 真相以 `design/产品优化方案终版-0727/`、`design/design-tokens.json` 和真实 React UI 为准；
- 海报与直播场次相互独立，旧稿中与当前领域模型冲突的文案不得直接进入产品；
- `grid-wrap` 始终保持固定两页兼容，新布局与自动分页按活跃路线图实施；
- 新的正式交互原型位于 `design/prototypes/`，本目录仅作视觉探索参考。

预览文件：

- `apple-ui-preview.html`：Apple 式明亮工作台探索；
- `liquid-glass-preview.html`：轻量 Liquid Glass 单页探索；
- `streamer-workbench-liquid-glass.html`：包含导航与交互状态的完整探索。
