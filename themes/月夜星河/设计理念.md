# 月夜星河 · 设计理念

> 蓝图 v0.1 M0.3 第 8 套主题包。深色直播舞台感。

## 定位

- **场景**：夜场弹唱 / 抒情慢歌 / 星空主题海报
- **使用**：和 `live-set`（直播复盘）/ `learning-report`（学歌报告）/ `fullscreen-flow`（全屏绕排）都搭
- **对比**：海洋柔光（白天 / 清爽） vs 月夜星河（夜晚 / 深邃）

## 配色令牌

| 角色 | RGB | 用途 |
| --- | --- | --- |
| text | (245, 240, 225) | 暖白 #F5F0E1 — 歌名主体（避免纯白刺眼） |
| label | (255, 184, 77) | 琥珀 #FFB84D — 分类标签（一字/二字/...） |
| pill | (20, 30, 60, 180) | 半透明深底 — 分类胶囊（柔和描边） |
| line | (255, 165, 0) | 琥珀细线 #FFA500 — 段落下划线（聚焦线） |
| mist | (180, 200, 255, 60) | 星云柔光 — 阅读区底纹（防止纯黑） |

## 背景生成

- 1080×1920 (9:16) + 1080×2400 (9:20) 两张
- 三段渐变：深蓝紫 #0A0E2A → 深紫黑 #1A1538 → 深蓝黑 #0C1228
- 顶部柔光圆（暖白 255/220/180，3 层叠加 + 高斯模糊 80）— 暗示月光
- 散布星点：约 60-90 颗小星 + 6 颗带十字光芒的亮星
- 微噪声（±3 RGB，30% 混合）— 避免纯色平面感
- 随机种子 20260802 — 确定性生成
