## 1. 背景与定位

### 1.1 为什么需要这一层

主播工作台现状：曲库、事件、海报、直播会话、快照、导入导出都是**纯本地**（L1.5 OnlineStatusBadge 离线检测已就位）。

但用户在新加歌曲、查封面/时长、补 LRC 歌词时，仍然是手填——这是"工具箱"定位的明显空缺。

**M2.7 要做的事**：搭一个**可插拔的在线元数据层**，让"在线可选"成为工具箱能力，但不破坏纯离线定位。

### 1.2 借鉴来源

| 项目 | 借什么 |
|---|---|
| UnblockNeteaseMusic | **多 provider 路由 + 自动回退**（核心架构借鉴） |
| neteasecloudmusicapienhanced | API 表面广度（search / song / artist / album / playlist / lyric） |
| L-1124/QQMusicApi | QQ 音乐公开接口 schema 参考 |
| YesPlayMusic / VutronMusic | 客户端 + 本地混合的 UX 范式（**M2.9+ 才用到**） |

**灰色版权 / 灰色音乐流**：本项目**不**做；只用公开 API 拉元数据（cover/lrc/duration/artist bio），不解析播放 URL、不入库任何 mp3/m4a。

### 1.3 关键原则

1. **核心数据 100% 离线**（songs/events/posters/live-sessions/settings）—— 铁律
2. **辅助元数据在线可选**（cover/lrc/duration/artist bio）—— 本层服务对象
3. **离线降级**：OnlineStatusBadge 离线时所有「在线」按钮自动灰掉
4. **不锁单一 provider**：Router 默认按优先级依次尝试，任一可用即用
5. **数据落本地缓存**：命中后存 `data/metadata/<provider>/<key>.json`，二次访问零网络
6. **TTL 30 天**：过期自动重拉；用户主动「强制刷新」绕过
7. **零凭证**：只用公开 API（不需要登录态的接口）
8. **零新增依赖**：用 stdlib `urllib.request`，不引 requests/httpx
9. **失败透明**：调 API 失败 → 抛 `MetadataUnavailable`，上层 M2.6 useApiError toast 化

## 3. 核心协议：MetadataProvider

```python
# core/metadata/protocols.py
from typing import Protocol
from .types import Hit, SongDetail, LyricContent, ArtistDetail, AlbumDetail, PlaylistDetail, Chart

SearchType = Literal["song", "artist", "album", "playlist"]


class MetadataProvider(Protocol):
    """单一在线音乐服务的元数据访问接口。
    
    M2.7 阶段所有方法都是同步实现（与现有 server 路由一致）。
    异步化在确有性能瓶颈时再做。
    """
    
    name: str  # "netease" / "qq" / "kugou" / ...
    
    def search(self, keyword: str, *, type: SearchType = "song",
               limit: int = 20) -> list[Hit]: ...
    
    def get_song(self, song_id: str) -> SongDetail: ...
    
    def get_artist(self, artist_id: str) -> ArtistDetail: ...
    
    def get_album(self, album_id: str) -> AlbumDetail: ...
    
    def get_playlist(self, playlist_id: str) -> PlaylistDetail: ...
    
    def get_lyric(self, song_id: str) -> LyricContent | None: ...
    
    def get_charts(self) -> list[Chart]: ...
    
    def get_similar(self, song_id: str) -> list[Hit]: ...
```

**设计要点**：
- Protocol 而非 ABC：避免具体 provider 继承负担，duck typing 友好
- `name` 字段强制：cache key 前缀、router 日志、UI 标记都用
- `get_lyric` 返回 None 表示"无歌词"（不是失败，是有意义的空）
- 抛 `MetadataUnavailable` 表示"网络/限流/服务挂了"
- 抛 `MetadataNotFound` 表示"请求合法但查不到"

## 5. HttpClient

```python
# core/metadata/http_client.py
class HttpClient:
    """薄 HTTP 客户端封装（基于 stdlib urllib.request）。
    
    特性：
    - 默认 User-Agent（避免被 403）
    - 超时（默认 10s）
    - 指数退避重试（最多 2 次，5xx / 网络错误触发；4xx 不重试）
    - 同 provider 速率限制（≥ 200ms 间隔）
    """
    
    def __init__(self, *, user_agent: str = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_7) ...",
                 timeout: float = 10.0, max_retries: int = 2, min_interval: float = 0.2):
        self._ua = user_agent
        self._timeout = timeout
        self._max_retries = max_retries
        self._min_interval = min_interval
        self._last_call_at: float = 0.0
        self._lock = threading.Lock()  # 同 provider 串行
    
    def get_json(self, url: str, *, params: dict | None = None) -> dict:
        """GET → 解析 JSON。失败抛 MetadataUnavailable。"""
        ...
    
    def get_text(self, url: str, *, params: dict | None = None) -> str:
        """GET → 文本。失败抛 MetadataUnavailable。"""
        ...
```

**关键决策**：
- 用 stdlib 而非 requests → 零新增依赖
- `threading.Lock` 同 provider 串行 → 简单可靠的速率限制（≥200ms 间隔）
- 4xx 不重试（客户端错误，重试无意义）；5xx + 网络错误才重试
- 解析失败抛 `MetadataUnavailable`（业务层统一处理）

## 6. MetadataCache

```python
# core/metadata/cache.py
class MetadataCache:
    """本地元数据缓存。
    
    存储路径: <base_dir>/<provider>/<key>.json
    文件格式: { "fetched_at": ISO8601, "payload": <provider-specific dict> }
    TTL: 默认 30 天，force=True 绕过。
    """
    
    def __init__(self, base_dir: Path, *, ttl_seconds: int = 30 * 24 * 3600):
        self._base = base_dir
        self._ttl = ttl_seconds
        self._base.mkdir(parents=True, exist_ok=True)
    
    def get(self, provider: str, key: str, *, force: bool = False) -> dict | None:
        """读缓存。返回 None 表示未命中或过期。"""
        path = self._path(provider, key)
        if not path.is_file():
            return None
        try:
            with path.open("r", encoding="utf-8") as f:
                envelope = json.load(f)
        except (json.JSONDecodeError, OSError):
            return None
        if not force and self._is_expired(envelope.get("fetched_at", "")):
            return None
        return envelope.get("payload")
    
    def put(self, provider: str, key: str, payload: dict) -> None:
        """写缓存。原子写（tmp + rename）。"""
        path = self._path(provider, key)
        path.parent.mkdir(parents=True, exist_ok=True)
        envelope = {
            "fetched_at": datetime.now().astimezone().isoformat(timespec="seconds"),
            "payload": payload,
        }
        # 原子写：tmp file in same dir + os.replace
        ...
    
    def clear(self, provider: str | None = None) -> int:
        """清缓存。provider=None 清全部。返回删除条目数。"""
        ...
    
    def _is_expired(self, fetched_at: str) -> bool:
        if not fetched_at:
            return True
        try:
            dt = datetime.fromisoformat(fetched_at)
        except ValueError:
            return True
        return (datetime.now().astimezone() - dt).total_seconds() > self._ttl
    
    def _path(self, provider: str, key: str) -> Path:
        # key sanitize: 只保留 [a-zA-Z0-9_-]，避免路径注入
        safe = "".join(c if c.isalnum() or c in "-_" else "_" for c in key)
        return self._base / provider / f"{safe}.json"
```

**关键决策**：
- envelope 格式（带 `fetched_at`）→ TTL 检查是 cache 自己的事，provider 不关心
- 原子写（tmp + rename）→ 防止写到一半被 kill 导致缓存损坏
- key sanitize → 防止 provider 给的 song_id 包含 `/` 导致目录穿越
- 读缓存失败不抛 → 静默返回 None，让上层重新拉

## 7. MetadataRouter

```python
# core/metadata/router.py
class MetadataRouter:
    """多 provider 路由器。
    
    按 provider_order 依次调用；任一成功即返回。
    全部失败抛 MetadataUnavailable（带每个 provider 的错误列表）。
    
    缓存策略：read 路径先查 cache，miss 再走 provider；write 路径自动写 cache。
    """
    
    def __init__(self, providers: list[MetadataProvider],
                 cache: MetadataCache | None = None):
        if not providers:
            raise ValueError("router 至少需要 1 个 provider")
        # 去重 + 按 name 排序日志友好
        self._providers = list(providers)
        self._cache = cache
    
    @property
    def provider_names(self) -> list[str]:
        return [p.name for p in self._providers]
    
    def search(self, keyword: str, *, type: SearchType = "song",
               limit: int = 20, use_cache: bool = True) -> list[Hit]:
        """依次调 provider 搜索；首个有结果即返回。"""
        ...
    
    def get_song(self, song_id: str, *, preferred_provider: str | None = None,
                 use_cache: bool = True) -> SongDetail:
        """按 provider 顺序查。preferred_provider 排第一。"""
        ...
    
    # get_artist / get_album / get_playlist / get_lyric / get_charts / get_similar 同模式
```

**关键决策**：
- `use_cache=False` 用于强制刷新场景（M2.9 UI「强制刷新」按钮）
- 失败的 provider 记日志但继续往下走（一个挂掉不影响其他）
- 全部失败时抛 `MetadataUnavailable(errors=[(name, exc), ...])`，UI 可以提示「3 个源都不可用」
- 缓存命中直接返回，不调 provider（节省时间 + 避免被限流）
- `preferred_provider` 让 UI 可以优先用上次成功的源

## 8. 错误类型

```python
# core/metadata/errors.py
class MetadataError(Exception):
    """metadata 层基础异常"""
    pass


class MetadataNotFound(MetadataError):
    """provider 全部都查不到（合法请求，无结果）"""
    pass


class MetadataUnavailable(MetadataError):
    """所有 provider 失败（网络/限流/5xx）"""
    def __init__(self, errors: list[tuple[str, Exception]]):
        self.errors = errors
        names = ", ".join(name for name, _ in errors)
        super().__init__(f"所有 provider 都不可用：{names}")


class MetadataRateLimited(MetadataError):
    """被限流（429）"""
    def __init__(self, provider: str, retry_after: int | None = None):
        self.provider = provider
        self.retry_after = retry_after
        super().__init__(f"{provider} 被限流")
```

**关键决策**：
- `MetadataNotFound` vs `MetadataUnavailable` 区分：前者"没结果"后者"无法尝试"
- `MetadataRateLimited` 单独一类：UI 可以专门提示"稍后重试" + 等 retry_after 秒

## 10. 测试策略

`tests/test_metadata.py` 覆盖：

1. **协议层** — 用 `FakeProvider` 实现 MetadataProvider 协议的所有方法，验证 duck typing

3. **errors** — 三种异常的构造、属性、`__str__`

   - 5xx 重试到 max_retries 后抛错
   - 超时抛错
5. **cache** — 临时目录：
   - get 命中 / miss
   - put 后 get 拿到

   - 首个成功即返回（不调第二个）
   - 首个失败 → 第二个成功
   - 都失败 → MetadataUnavailable 带 errors 列表
   - 缓存命中不调 provider
   - use_cache=False 强制刷新
   - preferred_provider 排第一
