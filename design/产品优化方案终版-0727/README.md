## 当前代码事实快照

以下是**当前状态**，不是目标状态：

- 7 套主题，但只有 `grid-wrap` 一个真实布局；
- 画布 UI 只有 1080×1920 和 1080×2400 两个预设；
- 金标准 16/16 diff=0；
- 歌曲数据 v4，共 178 首，状态仅 `active/draft` 两态；
- S1 事件日志、S2 点歌双写、S3 曲谱管理已上线；S4 学歌打卡、S5 统计视图未完成；
- Electron/PyInstaller 仅完成 spike，正式壳、用户目录外置和全局快捷键未完成；
- Palette、Skin、Preset、anchors、FreeformLayout、自定义编辑器均为目标设计，尚未实现；
- React 工作台可用，但暗色令牌、组件体系、动效、响应式和无障碍仍需系统升级；
- benchmark 工具尚未建立，33.8ms 仅是既有记录，不是自动化性能基线。

## 核心结论

> 不整项目重写；保留 PIL 引擎、数据层、FastAPI、React、插件思想和金标准。重构产品表达层、布局运行时、主题/皮肤边界、工作台状态与桌面产品化能力。

*本目录建立后，新增产品级决策应优先修改终版，不再分别维护三份前序方案。*
