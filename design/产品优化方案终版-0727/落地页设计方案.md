## 1. 设计哲学（已从"晨光纸感"升级为 A+B 混合方案）

> **暗色舞台（默认）**：演出后台的"聚光灯美学"——深暖黑 OLED 底 `#0A0F0D`，舞台金 accent `#E8A33D`，超大衬线标题，克制的 glow 光效。海报是被展示的作品，页面是它们的剧场。
> **画廊白（日间）**：博物馆的"白墙留白"——暖纸白底 `#FAF8F5`，海洋青 accent `#2F8F7A`，不对称 Editorial Grid，海报是挂在墙上的画。
> **落地页本身 = 主题工坊 + 布局系统 的产品 demo**——品牌切换按钮直接演示"主题是一组设计令牌"的产品概念。

落地的三个具体含义：

1. 落地页的**主题切换交互**本身就是产品核心能力（7 主题切换实时预览）的提前打样
2. 落地页的**布局展示区**直接使用产品 v1 的 grid-wrap 截图 + v2 规划的 halo/editorial/collage 风格示意
3. 落地页的**信息架构** = 产品功能列表的"产品化讲述"（不是简单列特性）

## 4. 视觉系统（v2 — A+B 混合方案）

> **2026-07-27 更新**：从原"晨光纸感 × 演出后台"升级为「暗色舞台 Cinematic Stage × 画廊白 Art Gallery」双品牌。单源真值 `design-tokens.json` v2，已落地到 `site/landing/index.html`。

### 4.1 4 种状态 = 品牌(2) × 明暗(2)

```
                    暗色舞台 (stage)                 画廊白 (gallery)
          ┌────────────────────────────────┬──────────────────────────────┐
暗 (Dark)   │ 深暖黑 OLED #0A0F0D            │ 深夜绿 #15201C               │
           │ 舞台金 accent #E8A33D           │ 海洋青 #4DBB9E              │
           │ 聚光灯 glow 光效 · 克制克制       │ 无 spotlight 效果              │
           │ ★ 产品门面默认态                  │                              │
亮 (Light)  │ 暖灰白 #F0EDE8                 │ 暖纸白 #FAF8F5              │
           │ 海洋青 #2F8F7A                   │ 海洋青 #2F8F7A              │
           │ 白天演示/截图场景                 │ 日间浏览 · 长时间阅读           │
           └────────────────────────────────┴──────────────────────────────┘
```

- `[data-brand="stage|gallery"][data-mode="dark|light"]` 双 attribute 控制；
- 品牌切换 = 整个色板替换（`design-tokens.json` 中 `colors.stage.*` vs `colors.gallery.*`）；
- 明暗切换 = 同一品牌内环境适配；
- `spotlight` 颜色角色仅 stage 品牌使用，gallery 品牌回退为 none。

### 4.2 设计令牌（单源真值 `design-tokens.json` v2）

落地页 CSS 变量直接从 `design-tokens.json` v2 的 `colors.stage.dark` 等节派生。关键差异化角色：

| 角色 | 说明 | stage 暗 | gallery 亮 |
|---|---|---|---|
| `--bg` | 页面底色 | `#0A0F0D` | `#FAF8F5` |
| `--primary` | 品牌主色 | `#3BAF94`（亮海洋青） | `#2F8F7A`（海洋青） |
| `--spotlight` | 舞台聚光灯（仅 stage） | `#E8A33D`（舞台金） | `transparent` |
| `--accent` | 辅助暖色 | `#E8956E` | `#D9764F` |
| `--grain-opacity` | 纸张颗粒强度 | `0.04` | `0.018` |
| `--glow-hero` | Hero 光晕（仅 stage） | `0 0 120px rgba(E8A33D,0.14)…` | `none` |
| `--shadow-card` | 卡片投影 | 深投射（OLED 对比） | 浅投射（纸感） |
| `--ease-cinematic` | 电影级缓动 | `cubic-bezier(.16,1,.3,1)` | 同 |

完整令牌见 `design/design-tokens.json`。

### 4.3 字体

- 衬线大标题：`Noto Serif SC` (Google Fonts, 400/600/700/900)
- 正文：`PingFang SC / Microsoft YaHei / Noto Sans SC`
- 等宽数字/标签：`JetBrains Mono` (Google Fonts, 400/500)
- 加载策略：`<link rel="preconnect">` + `font-display: swap`

### 4.4 视觉范式

- **纸张颗粒**：SVG fractalNoise 内联，`body::after` 覆盖全视口，`opacity: var(--grain-opacity)`
- **环境光晕**：`::before/::after` 伪元素，`filter: blur(60-80px)`，stage 品牌用 spotlight 金 + primary 青，gallery 品牌只用 primary 青
- **投影**：stage 深投射（`rgba(0,0,0,0.4-0.6)`），gallery 浅投射（`rgba(26,38,34,0.04-0.10)`）
- **缓动**：页面级过渡用 `--ease-cinematic`（0.5s），微交互用 `--ease-out`（0.2-0.3s），Hero 标题用 `--ease-spring`

## 5. 核心交互设计

### 5.1 Hero 主题切换 demo（关键体验）

**位置**：Hero 区右半屏

**交互范式**（借鉴 `prototype/index.html:951-991` 的 `swapPoster()`）：
- 7 张主题 poster（`prototype/posters/*.png`，每套主题第 1 页 240×426px）
- 顶部 7 个主题 chip（圆点+名字），点击或键盘 `1-7` 切换
- 主海报图 `<img>` crossfade 200ms（双图叠加淡入淡出）
- 同步：底部光晕 `--poster-glow` 切主题色（CSS 变量驱动）
- 切换主题时**主题自身色**注入页面（`--primary` 临时覆盖回原值前短暂展示新主题色）
- 当前主题海报外环显示呼吸阴影

**键盘**：←→ 切主题，↑↓ 切页（1/2），Esc 复位
**动效**：首次进入 stagger 入场（30ms 间隔），新主题入场 200ms ease-out

**特殊：作为"主题工坊"产品能力打样**
- 鼠标悬停主题 chip 时，主图只**预览**（透明度 60%），松手回原状态；点击 = 确认切换
- 主题 chip 右侧 mini 色板条（5 角色，与 themes.html:98-104 同款），强化"主题是一组设计令牌"的产品心智

### 5.2 布局系统预览区（v2 路线图打样）

**位置**：第 5 视口

**展示策略**（不画大饼，诚实标注）：
- 6 套布局卡片，每张 = **缩略图 + 名称 + 一句话定位 + 状态徽章**
- 状态徽章：
  - `v1 已上线`（grid-wrap）
  - `v2 规划中`（halo / editorial / collage / flow / minimal）
- 缩略图：grid-wrap 用真实 `prototype/posters/ocean-1.png`；其他 5 张用 **SVG 占位示意图**（手绘风白底图，标注"规划预览"），避免画饼感
- 点击卡片 → 锚点跳到产品优化方案 v2 章节（内部 anchor）

**为什么这样做**：诚实比吹牛更重要，技术读者一眼能看出"哪些是真、哪些是规划"，信任度更高。

### 5.3 直播伴侣三件套（场景化展示）

**位置**：第 3 视口（紧跟数字条，让情绪不断）

**三列卡片**（每张卡 = 模拟截图 + 一句话痛点）：
1. **点歌队列**：卡片 = `QuickView.tsx` 风格截图（手机竖屏示意），副标题"今晚唱过的，一键进历史"
2. **速查 /quick**：卡片 = 大字歌名 + 选调，副标题"3 米外都能读 · 键盘全搞定"
3. **T 键看谱**：卡片 = 曲谱图片占位 + 直播模式，副标题"曲谱随叫随到，不切窗口"

每张卡片 hover 时**模拟交互点亮**（状态指示符依次出现），强化"这工具真的能这样用"。

### 5.4 产品演进时间线

**位置**：第 6 视口

**形式**：三段式（v1 / v2 / v3）
- v1（当前）：海报生成 + 歌曲库 + 学歌
- v2（进行中）：布局子系统重构 + 多布局 + 自定义
- v3（未来）：数据驱动布局 + 多设备同步

每段 = 简短标题 + 一段话 + 一个跳转链接（v1 跳 GitHub README，v2 跳本产品方案终版，v3 跳路线图）。

### 5.5 主题切换器（导航条右侧）

```
[logo] 歌单海报         [主题: 晨光纸感 ▾] [☀/🌙]      [★ Star on GitHub]
```

- 主题下拉：晨光纸感 / 演出后台（双选），切换时整个页面令牌切换（150ms 过渡）
- 亮暗切换：亮 / 暗（双选），独立于主题
- 状态写 localStorage，下一次进入恢复
- Star 按钮：纯跳转 GitHub 仓库（在新标签页打开）

## 7. 技术架构

### 7.1 技术栈

```
astro@4              静态生成，零 JS 默认
@astrojs/tailwind    Tailwind 集成
tailwindcss@3        工具类（@theme 与设计令牌打通）
@astrojs/sitemap     SEO sitemap
sharp                构建期图片优化（生成海报缩略图 webp）
@astrojs/mdx         （可选）如要把产品方案作为 /design 路由
```

**为什么不用 framer-motion / GSAP**：落地页动画用 CSS 变量 + `@starting-style`（modern browsers）即可，crossfade 用 transition 200ms；GSAP 体积（~30kb gzipped）对落地页不划算。

├── tsconfig.json
├── public/
│   ├── posters/                 # 从 prototype/posters/ 软链/复制（14 张）
│   ├── thumb-poster/            # 构建期 sharp 生成 360×640 webp

### 7.3 部署

**Vercel（主）**：
- `vercel.json` 配置 `outputDirectory: "site/landing/dist"`，自动 Preview Deploy
- 自定义域名（如有）

**GitHub Pages（备）**：
- `site/landing/dist/` 通过 GitHub Actions 部署到 `gh-pages` 分支

## 9. 风险与边界

| 风险 | 对策 |
|---|---|
| **画饼感**（v2 规划的功能被当 v1 宣传） | 布局卡片明确标 "v2 规划中" + 缩略图用 SVG 占位 |
| **多主题增加维护成本** | 4 种状态 = 2 套令牌 × CSS 属性选择器；不写两套样式，靠 CSS cascade 自动覆盖 |
| **快速过时的产品截图** | poster 来源于 `prototype/posters/`，主题/布局变化时需手动重渲；定期（每季度）检查 |
| **SEO 与"个人工具"定位矛盾** | 不强求 SEO 第一页，meta + sitemap 够用；目标受众不是搜索引擎 |
| **跨浏览器** | `@starting-style` 需 modern browsers；fallback 用 `animation` 关键帧 + 立即显示 |

**明确不做**：
- 不做账号/登录/评论/订阅（个人工具属性）
- 不做"在线试用"（产品本身是桌面 App，未到上线期）
- 不做多语言切换（中文为主）
- 不做博客/新闻板块（独立站价值低，文档在 GitHub）
