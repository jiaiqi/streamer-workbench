# R4 退出条件 #3 收口设计稿 — 专用海报区产生日活

> **目标**：把 R4 退出条件 #3「专用海报区产生日活（live-set / learning-report 各有使用证据）」从「等待部署后观察」转成「可被实时查询的日活面板」。
>
> **状态**：🟡 设计稿（本批收口 #3，#2 草稿/手动分页 UI 留待下批）
>
> **日期**：2026-08-16

---

## 1. 背景

R4 退出条件 #3 原本是「等真实用户使用 live-set / learning-report 两个专用海报布局后再观察」。但「等观察」其实是把验证卡在外部依赖上。

实际情况：
- `events.jsonl` 已有完整事件流：live.py /poster 写 `meta.kind="live-poster"`，learning_report.py /poster 写 `meta.kind="learning-report"`
- EventStore 支持 `EventQuery(event_type, since, until)` 时序过滤
- SpecialPostersPanel 已有专用海报区入口

本批把「等观察」改成「可实时查询 + 实时展示」。

---

## 2. 设计目标

### 2.1 收口判据

- [x] 新增 `GET /api/posters/special-stats?days=30` 端点
- [x] 端点聚合 `poster_exported` 事件中 `meta.kind` 为 `live-poster` / `learning-report` 的事件
- [x] 按时间窗口过滤（默认 30 天，可配 1-365）
- [x] 返回 `totals`（总数）+ `recent`（最近 5 条详情）+ `by_day`（按日分布，可选）
- [x] `SpecialPostersPanel` 顶栏加日活徽章
- [x] 自动化测试覆盖（pytest 端点 + vitest UI 渲染）

### 2.2 不在本批范围

- 草稿/手动分页 UI（V3 推动，留给下批）
- 真实日活历史趋势图（等数据真有 30+ 天再做）
- 用户/账号维度（暂时单机本地版，不做账号隔离）

---

## 3. 实现方案

### 3.1 后端：新增 1 个端点

**`server/routers/posters.py`** 新增：

```python
@router.get("/api/posters/special-stats")
def api_special_poster_stats(
    req: Request,
    days: int = Query(30, ge=1, le=365, description="时间窗口天数，1 ~ 365"),
):
    """R4 退出条件 #3: 专用海报区日活统计。

    事件源：events.jsonl 的 type=poster_exported 事件，meta.kind ∈ {live-poster, learning-report}
    聚合维度：最近 N 天总数 + 最近 5 条详情
    """
```

**返回结构**：

```json
{
  "days": 30,
  "since": "2026-07-17T00:00:00+08:00",
  "totals": {
    "live_poster": 12,
    "learning_report": 5
  },
  "recent": [
    {
      "kind": "live-poster",
      "occurred_at": "2026-08-12T22:00:00+08:00",
      "title": "周三晚点歌",
      "session_id": "live_xyz"
    }
  ],
  "by_day": {
    "2026-08-12": {"live_poster": 2, "learning_report": 1},
    "2026-08-11": {"live_poster": 1, "learning_report": 0}
  }
}
```

### 3.2 Response Model

`server/api/secondary_models.py` 新增 `SpecialPosterStatsResponse` + 子结构（frozen dataclass + Pydantic model）。

### 3.3 前端：日活徽章

**`ui/src/posters/SpecialPostersPanel.tsx`** 顶栏加：

```
┌────────────────────────────────────────┐
│ 专用海报                  日活徽章:    │
│                         📊 近 30 天   │
│ [live-set 入口] [learning-report 入口] │  直播复盘 12 张
│ [LiveSession 列表...]                  │  学歌报告  5 张
└────────────────────────────────────────┘
```

- mount 时拉一次 stats
- 导出成功后 invalidate refetch

### 3.4 Client API

**`ui/src/api/posters.ts`** 新增 `getSpecialPosterStats(days: number)`。

## 4. 风险与回退

| 风险 | 概率 | 应对 |
|---|---|---|
| events.jsonl 太大 iter 慢 | 低 | R3.6 已用 EventStore 索引（启动期建索引，O(1) 查询） |
| 端点路径冲突 | 低 | `/api/posters/special-stats` 不会被 `/api/posters/{poster_id}` 匹配（无 path param） |
| meta.kind 不存在（旧事件） | 低 | 端点对 kind 缺失的旧事件按"未知种类"不计入；测试覆盖 |
