## 4 状态决策依据

### 为什么不是 3 主题而是 4 状态

你最初问的是"3 主题都支持"。评审下来走的是**明暗 × 双品牌** = 4 状态：

```
              画廊白（产品工具）       暗色舞台（直播/门面）
亮态     ▢ 默认进入（首屏）         ▢ 白天/演示场景
暗态     ▢ 夜间/长时阅读            ▢ 演出场景（默认）
```

理由：
- 双品牌（画廊白 vs 暗色舞台）= **两套不同心智**：前者"工具感"，后者"舞台感"
- 明暗 = **同一品牌的环境适配**，成本极低（同一令牌换 BG）
- 4 状态 = 2×2 矩阵，CSS 属性选择器一键切换，**不写两套样式**

## 视觉方向建议

### 画廊白（旧名 Dawn）

- **主轴**：温柔清新，长时间阅读不累
- **Hero 区**：大留白 + 衬线标题 + 暖珊瑚 + 海洋青的双色渐变光晕
- **适用受众**：主播本人 + 白天使用的潜在主播
- **风险**：纸感做得过强会显得"工具感"，但落地页需要"产品门面"的硬朗，**适度克制纸张颗粒（亮 0.028 / 暗 0.05）**

### 暗色舞台（Stage）

- **主轴**：演出场景，3 米外可读（quick 速查的延伸）
- **Hero 区**：近黑舞台底 + 墨绿 + 琥珀 + 红，对比强烈
- **适用受众**：技术读者（默认暗色调）+ 演出场景
- **风险**：暗色用得太多会显得"开发者向"，需要琥珀/暖珊瑚做情感锚

## 主题切换交互的产品心智

4 状态不是"装饰选项"，是产品能力的提前打样：

- **主题 = 一组设计令牌**（与设计文档 §5「主题工坊」一致）
- **切换主题 = 整个站点视觉重构**
- 这就是 v2 主题管理视图要做的事，**落地页自己就是它的 demo**
