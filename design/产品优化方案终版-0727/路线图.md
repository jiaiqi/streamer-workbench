## 2. 全程质量门

1. `core/` 不依赖 UI/服务器；
2. 触及旧渲染路径必须保持金标准 16/16 diff=0；
3. 禁止用新引擎自举覆盖旧基线；
4. Python 改动运行单元测试；React 改动运行 `tsc --noEmit`；
5. 持久格式必须 schemaVersion + 备份 + 迁移测试；
6. 用户可写数据不进入打包临时资源；
7. 新 UI 同时考虑亮暗、键盘、reduced motion、错误和断点；
8. 阶段结束更新 README/HANDOFF/路线图状态；
9. 每个提交只解决一个可验证问题；
10. 未经测量的性能只能称候选目标，不能写成已达基线。
