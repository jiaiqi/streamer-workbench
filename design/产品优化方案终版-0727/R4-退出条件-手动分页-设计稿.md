# R4 退出条件 #2 收口设计稿 — 草稿/手动分页 UI V3（第一版）

> **目标**：把 R4 退出条件 #2「草稿/手动分页 UI」从「V3 推动」转成「可用的最小版本」。
>
> **状态**：🟡 设计稿（V3 MVP）
>
> **日期**：2026-08-16

---

## 1. 背景

R4 v2 抽象层已为「手动分页」打好地基：
- `PagePolicy.mode` 支持 `manual` / `auto` / `legacy-fixed-2` 三种
- `page_policy.manual_pages: list[dict]` 字段已存在
- `magazine-flow` layout 已声明 `supports_manual_pages=True`
- 校验路径已覆盖（`manual` 必须有 manual_pages 列表）

但**没有 UI** — 用户无法编辑 manual_pages，无法切到 `mode=manual`。本批把 UI + 渲染链路补齐到 MVP。

V3 完整版（拖拽每页排序 + 每页主题覆盖 + 自动 save）按需推到下批。

---

## 2. 设计目标

### 2.1 收口判据

- [x] 新增 4 个端点：`GET / POST / PATCH / DELETE /api/posters/{id}/pages*`
- [x] `engine.render_pages` 支持 `manual_pages` 参数（按列表渲染，不调 layout.analyze）
- [x] 新组件 `PagesPanel` 集成在 workspace 左栏
- [x] Add/Delete/Reorder 三件套可用
- [x] 切到 magazine-flow 时可启用；grid-wrap 灰显
- [x] 自动化测试覆盖（pytest + vitest）

### 2.2 不在本批范围

- 每页主题/画布 override（V3 增强推到下批）
- 自动 save（用户手动点保存，V3 增强做实时 save）
- 拖拽缩略图重排（M3 P2 已有 HTML5 DnD 模式，本批先用上下箭头按钮更稳）

---

## 3. 实现方案

### 3.1 后端：4 个新端点

**`server/routers/posters.py`** 新增：

```python
@router.get("/api/posters/{poster_id}/pages")
def api_posters_pages_list(poster_id: str, req: Request):
    """列出当前海报的页面（real = render 实际会生成的页数）。"""
    
@router.post("/api/posters/{poster_id}/pages")
def api_posters_pages_add(poster_id: str, req: Request):
    """追加一页到 manual_pages 列表。"""

@router.patch("/api/posters/{poster_id}/pages")
def api_posters_pages_reorder(req: Request, payload: PosterPagesReorderRequest):
    """批量重排 manual_pages。"""

@router.delete("/api/posters/{poster_id}/pages/{index}")
def api_posters_pages_delete(poster_id: str, index: int, req: Request):
    """删除指定 index 的页。"""
```

每次修改都触发 `page_policy.mode = "manual"` 切换（自动）。

### 3.2 渲染链路

**`core/engine.py`** `render_pages` 增强：

```python
def render_pages(theme, layout, library, spec, font_path, *,
                 page_count=None, parameters=None,
                 palette=None, skin=None,
                 manual_pages=None) -> list[Image.Image]:
    """R4 v3: 接受 manual_pages，覆盖自动分页。
    
    manual_pages 为 None 时，行为与 V2.4 一致（按 layout.analyze 决定）。
    manual_pages 为 list 时，按列表生成 Image（每个 dict 一页）。
    """
```

- `reorderPages(posterId, newOrder)`

## 4. 风险与回退

| 风险 | 概率 | 应对 |
|---|---|---|
| manual_pages 与 layout.analyze 互斥 | 中 | 切到 manual 模式时强制忽略 analyze 输出 |
| 端点路径冲突 | 低 | `/api/posters/{id}/pages` 子路径，无冲突（与 `/api/posters/{id}/thumb` 同样模式） |
| 灰显边界条件 | 中 | 按 layout.capabilities()['supports_manual_pages'] 严格判断 |
