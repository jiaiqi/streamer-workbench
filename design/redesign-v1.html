重设计改动说明

设计概念「演出后台 Backstage」：直播时电脑常开，暗色护眼、高对比、一瞥可读；界面是工具，歌名是内容。

为什么改

  • 三个视图三套语言：学歌是"晨光纸感卡片+阴影渐变"，歌曲库是扁平表格，工作台又是另一套——像三个产品。
  • 难度表示打架：歌曲库 ◆◆◇（3 级）、学歌 5 星（2/3/4 星），数据模型只有简单/中等/困难三档。
  • 学歌两列固定网格浪费宽屏；导航 3 个"敬请期待"占位干扰。

统一语言

  • 单一墨绿强调；amber=待学/未会，green=已会，red=危险。
  • 层级靠填充阶梯（surface-1/2/3），不靠边框与阴影。
  • 圆角统一 10–14px；按钮只三档：实心 / 灰填充 / 危险幽灵。
  • 难度全站统一 ◆◆◇ 三级。
  • 歌名衬线（内容）、界面无衬线（工具）、选调等宽（数字）。

各视图要点

  • 工作台：主题列大卡片 → 紧凑行式（一屏看全 7 主题）；其余骨架不动。
  • 歌曲库：沿用已上线的响应式卡片网格，套新 token。
  • 学歌：两列固定 → auto-fill 响应式；5 星 → ◆◆◇；保留备注便签与一键学会。
  • 速查窗：升级为一等导航「直播模式」；近黑舞台底 + 超大选调保留。
  • 导航：4 个一等公民（工作台/歌曲库/学歌/直播），"敬请期待"全部移除，功能上了再加。

确认后落地

确认方向 → 我先抽统一 token 与共享组件（按钮/卡片/◆难度/状态点），再逐视图替换，每步跑类型检查 + 截图验证。
