重设计改动说明 · v2

设计概念「演出后台 Backstage」：直播时电脑常开，暗色护眼、高对比、一瞥可读；界面是工具，歌名是内容。

v2 评审修正（PM 评审 → 本稿落实）

  • P0直播模式三区重构：补回旧速查窗的"当前曲超大焦点区"——左搜索列表 / 中衬线大字歌名+等宽超大选调（3 米可读）/ 右今晚歌单；空搜索时 Enter 直接标记唱完，焦点区自动切下一首。
  • P0对比度全量过 WCAG AA：text-3 由 #5f675f（3.1:1 ✗）提至 #7d857d（4.8:1 ✓）；速查窗硬编码灰全部替换为达标 token；亮色主题同步修正（amber 加深至 4.6:1）。
  • P1状态点双编码：已会=✓实心点、未会=○琥珀空心环，不再只依赖颜色，色盲可辨。
  • P1字体策略修正：衬线仅保留在视图标题与直播大字焦点区；列表正文（卡片、速查行、队列）全部无衬线，避免暗底小字衬线发糊。
  • P1亮/暗入口去重：移除提案条上的重复切换按钮，仅保留侧栏入口；落地时默认跟随系统偏好+记住手动选择，进直播模式联动切暗。
  • P2补齐状态：搜索无结果/歌单为空/曲库空态；工作台新增「模拟渲染」加载骨架；预览缩放支持「适应 / 100%」一键切换。
  • P2语义色归一："选调未填"全站统一 amber（待补充），不再用灰色弱化。
  • 基础键盘焦点环可见、emoji 图标换 SVG、prefers-reduced-motion 支持。

统一语言

  • 单一墨绿强调；amber=待学/未会/待补充，green=已会，red=危险。
  • 层级靠填充阶梯（surface-1/2/3），不靠边框与阴影。
  • 圆角统一 10–14px；按钮只三档：实心 / 灰填充 / 危险幽灵。
  • 难度全站统一 ◆◆◇ 三级。
  • 标题与直播大字=衬线（内容），列表与界面=无衬线（工具），选调数字=等宽。

确认后落地

确认方向 → 先抽统一 token 与共享组件（按钮/卡片/◆难度/状态点），再按「歌曲库/学歌 → 工作台 → 直播模式」顺序逐视图替换，每步跑类型检查 + 截图回归 + 对比度校验。
