## 5. Queue

QuickView 队列位于浏览器 localStorage，不在仓库文件中，本次文件审计无法读取。角色 B 必须用显式 fixture 覆盖：

- 旧 `{title, sung, addedAt}` 队列；
- title 可唯一解析；
- title 无法解析；
- 迁移后按 song_id 恢复最新 title；
- 歌曲删除后使用 title_snapshot 降级；
- 重复迁移不重复队列项。

## 6. 角色 B dry-run 的期望基线

针对当前仓库 `data/`，预期至少报告：

```text
songs: 178 个 v4→v5 身份计划
tabs: 2 个目录、2 个文件迁移计划
presets: 1 个 v1→v2 Schema 迁移，0 个 custom_ids 关系迁移
events: 2 个 v1 只读兼容事件，不重写
unresolved: 0
conflicts: 0（若目标 ID 目录尚不存在）
```

如果 dry-run 与该基线不一致，先停止 apply，解释差异并由角色 A 复核。该快照之后若开发数据变化，需要重新采集，不得把旧数字作为永久断言。
