## 4. 数据与接口变更

### Tabs（`core/data/tabs.py`）

- `save_tab(tabs_root, song_id, filename, data)` / `delete_tab(tabs_root, song_id, relpath)`：第二参数语义由 title 改为 song_id，**签名位置不变**；非法 song_id（含 title、空值、穿越）抛 `ValueError`。
- 新增 `plan_migration` / `migrate_title_dirs(apply=)` / `rewrite_tab_files`。
- 物理目录：`data/tabs/{song_id}/{filename}`；`Song.tab_files` 路径格式同步变为 `tabs/{song_id}/…`。

### Preset（`core/data/presets.py`）

- `SongQuery` 新增 `unresolved: list` 字段；`custom_ids` 只接受 `song_<32hex>`。
- `Preset.schema_version` 默认 2；新增 `migrate_custom_ids`、`validate_song_query`、`new_preset_id`、`CURRENT_SCHEMA_VERSION`。
- `delete()` 返回值 `None → bool`（是否删到了东西）。
- `_from_dict` 容忍未知字段（前向兼容，旧 preset.json 可正常读）。

### Preset 路由（`server/routers/presets.py`）

- `POST /api/presets`：接受完整场景负载（原实现只存 id/name/layout_id，其余字段丢失）；无 id 自动生成。
- 新增 `POST /api/presets/{id}/duplicate`。
- `DELETE`：不存在 → 404；`_default` → 400。
- 保持 dict 负载，未引入 Pydantic（留给 R0.8）。

### 迁移器（`tools/migrate_data.py`）

- 子命令化：`bootstrap-songs`（原行为原样保留）+ `r05-relations`。
- `r05-relations`：`--data-root`、`--apply`（默认 dry-run）、`--report PATH`、`--queue PATH --queue-out PATH`（可选 QuickView 队列快照迁移）。
- `run_r05_migration()` 为可导入函数，测试直接调用。

## 5. 兼容、迁移与回滚

- **旧 title 目录**：迁移器搬迁，逐文件 sha256 校验；同名同内容幂等去重；同名异内容整目录停止并报 conflict（不覆盖、不写 JSON）；成功后旧目录移入 `data/backups/r05-migration-<ts>/tabs/`，不删除。
- **songs.json**：迁移顺带持久化 v5（确定性 `legacy_song_id`，与 A 侧规则一致未改动）；写入前完整备份到 `data/backups/r05-migration-<ts>/songs.json`。
- **Preset**：写入前 copytree 备份；未匹配歌名进 `song_query.unresolved`（不丢）；`schema_version` 1→2。
- **回滚**：备份目录内含迁移前 songs.json + presets/ + tabs 旧目录 + queue 快照，人工回拷即可；迁移可重复执行（重跑 planned=0、无新备份、零副作用）。
- **真实 data/ 未动**：开发与测试全部在临时目录；真实数据 dry-run 属 A3 联合验收。

## 8. 给角色 A 的集成说明（重要）

`server/routers/songs.py` 的 3 个 tabs 端点当前调用 `tabs_store.save_tab/delete_tab(TABS_DIR, title, …)`——**本分支合并后，title 会因非法 song_id 校验抛 ValueError（400）**，这是契约 §9 预期的中间态。按契约 §5.3 集成：

```python
# {identity} 先按 song_id 精确查找，未命中按 title 兼容查找
song = library.get_by_id(identity) or library.get(identity)
rel = tabs_store.save_tab(TABS_DIR, song.id, file.filename or "tab.png", data)
tabs_store.delete_tab(TABS_DIR, song.id, file)
# 响应同时返回 song_id、当前 title 和 tab_files
```
