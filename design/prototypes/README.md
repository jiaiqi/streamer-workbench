# 主播工作台交互原型

> 原型用于表达产品信息架构、视觉方向和交互契约，不代表相应能力已经实现。开发状态只以活跃路线图、ADR 和自动化测试证据为准。

## 原型关系

| 文件 | 定位 | 使用方式 |
|---|---|---|
| `streamer-workbench-ui.html` | 全产品工作台原型 | 表达海报、直播、歌曲库、学歌、统计和设置的完整信息架构；仍是 v3 规格中的主入口 |
| `streamer-workbench-ui-v2.html` | 海报闭环的聚焦方向原型 | 验证“画廊策展台”视觉方向以及歌曲集合、布局、主题、比例、分类、分页和按需导出的低学习成本流程 |

v2 不替代 `design/产品优化方案终版-0727/产品与技术规格-v3.md`、路线图、数据路线图或 ADR。两份 HTML 也不得用于推断 README 中的完成比例。

## v2 已表达的产品契约

- 海报是独立作品，不依附直播场次；名称、保存状态、选歌和导出均以海报文档为中心。
- Layout、Theme 和 Canvas 是独立维度：布局先声明可用比例，主题通过 Palette 独立选择。
- 当前只展示 `grid-wrap` 已声明的 9:20、9:16；3:4、4:5、1:1、A4 等候选比例不伪装成已支持。
- 分类可在按字数、按歌手、按掌握状态和不分类之间切换；类型、语言和标签待数据契约具备后扩展。
- 页数由已选歌曲、比例和分类开销估算，导出按钮展示实际页数，不写死两张。
- 八套中国传统色意象应用主色取自 `design/design-tokens.json` v3，只改变工作台交互语义，不改写海报 Theme/Palette。
- 亮暗模式与应用主色独立并在原型本地持久化；未知或不可用值回退到亮色和竹月青。
- 小于 800px 时降级为轻量预览与导出，不在窄屏隐藏关键配置后继续伪装成完整编辑器。

## 2026-07-29 交付验证

- HTML 使用 Python 标准解析器完成基本结构解析；内联 JavaScript 通过 `node --check`。
- 在 Chromium 中验证主题、9:20/9:16、四种分类、八套应用主色、亮暗模式和导出页数反馈。
- 验证应用主色切换前后海报正文颜色仍由主题 Palette 决定。
- 1440×900 桌面视口与 390×844 移动视口均无横向溢出。
- 390px 下歌曲栏和属性栏隐藏，轻量预览说明与导出 CTA 可见。
- 原生按钮、输入框、选择状态、图片替代文本、可见焦点和 `prefers-reduced-motion` 基础已覆盖。
- 浏览器控制台无 error / warning。

## 已知边界

- v2 使用静态歌曲快照和前端排版模拟，不等同于 PIL 最终渲染结果。
- `grid-wrap` 的正式兼容分页仍受 ADR-002 和 16 张金标准约束；原型的自动页数仅用于表达未来 `PosterDocument` 流程。
- 自定义页面的新增、删除、复制和重排仍受 R7 启动门限制，本原型不提前实现编辑器。
