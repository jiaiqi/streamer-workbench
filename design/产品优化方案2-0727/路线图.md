# 产品优化方案 v2 · 实施路线图（2026-07-27）

> **配套文档**：`产品优化方案v2-详细版.md`（方案正文，含架构细节、Schema 定义、API 清单）。
> **使用方式**：每个 Phase 内的任务按序执行；Phase 之间有依赖关系（见依赖图）；每完成一个任务跑一次 `tsc --noEmit` + 金标准（`PYTHONPATH=. python tests/test_golden.py`），原子提交。
> **原则**：不考虑人力与时间成本，以质量与最终体验为唯一标尺；但依赖顺序不可乱——地基不牢，布局白搭。

---

## 依赖总览

```
P0 布局子系统地基（引擎/主题/Schema）
   ├──→ P1 前端布局一等功能化 + 工作台重设计
   ├──→ P2 内置布局第一批（editorial/minimal/collage）
   ├──→ P3 内置布局第二批（halo/flow，技术峰值）
   └──→ P4 布局编辑器（自定义布局可视化）
            └──→ P5 数据驱动布局 + 与 S5 统计合流

并行支线（不阻塞主线，随时可插入）：
   S-a 视觉还债：暗色令牌化 / 组件对齐 / 动效落地
   S-b server 拆 routers + deps 依赖注入
   S-c roadmap 既有任务：S4 学歌打卡、S5 统计视图
```

> 验收：方案 §10「布局系统重构」全项。

| # | 任务 | 关键产出 | 守护 |
|---|---|---|---|
| 0.1 | `Shape` 模型 + `CanvasSpec.avoid_zones` 升级为 Shape 列表（元组自动转 rect 兼容） | `core/spec.py` | 金标准 |
| 0.2 | DrawContext 新增 `flow_right_edge(y)` / `flow_segments(y, shapes)`（形状×水平线求交）；grid-wrap 魔数迁移为默认 Shape 声明 | `core/context.py` | 金标准逐像素不变 |
| 0.3 | theme.json 增量字段：`anchors / skins / bg_strategy / mist_bottom`；`Theme` 模型扩展（全可选，缺省=现行为） | `core/themes/model.py`、`loader.py` | 金标准 |
| 0.4 | 字体角色多阶化：`Style.font_roles` + 引擎字体缓存；避让降字号 34 → `avoid_font_scale` | `core/style.py`、`core/engine.py` | 金标准 |
| 0.5 | 柔光底边、1920 基准、page_capacity 魔数收编（方案 §4.7 清单） | `mist.py`、`spec.py`、`base.py` | 金标准 |
| 0.6 | palettes/skins 两层：迁移脚本从 7 主题提取色板；skin 回退链（theme.skins[layout] → palette → 内置默认） | `palettes/`、迁移脚本 | 全主题 × grid-wrap 复跑 |

## 并行支线（随时可插入，不阻塞主线）

### S-a 视觉还债（建议与 P1 同步进行，因为 P1 会大面积动工作台代码）

1. 暗色令牌化：`:root`/`.dark` 双令牌块，删除全部 dark 三元表达式，防 FOUC 内联脚本；
2. React 组件对齐 shared.css 13 组件类（对齐率 15% → 100%）；
3. 动效落地：视图切换淡入上浮、列表 stagger、卡片选中 ring 动画、`prefers-reduced-motion` 降级。

### S-b server 拆分（建议在 P0.8 前完成，给 custom layouts API 腾位置）

1. `deps.py` 依赖注入替换模块级全局状态；
2. routers 五分（render/songs/export/events/settings），API 路径不变。

### S-c 既有 roadmap（原计划继续，不受本方案影响）

1. S4 学歌打卡（`/api/practice/log` + LearningView 打卡按钮 + 练习时间线）；
2. S5 统计视图（三端点 + 第五导航视图，暗色"演出后台"按 redesign-v2 新写）。
