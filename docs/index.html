布局系统

6 套布局，从规整到自由

同一首歌单 × 不同的"排版风格" = 截然不同的海报气质。环绕背景元素的 halo 版将于 2026 Q3 上线。

v1 已上线

全行网格绕排

分类胶囊 + 全宽网格，信息密度最高，178 首无压力。

v2 规划中

杂志双栏版

衬线刊头 + 双栏大留白，海报感最强，适合社交平台发布。

v2 规划中

环绕主体版 ★

歌名绕月亮/花束/唱片环排，不压背景主体，最"惊艳"。

v2 规划中

便签拼贴版

撕纸便签 + 微旋转 + 纸胶带，手账感，与奶油主题绝配。

v2 规划中

河流曲线版

歌名沿贝塞尔曲线排布，文字沿线微旋转，海洋主题 Signature。

v2 规划中

极简清单版

单列大留白 + 字号分级，本周新歌放大，高级感封面。
