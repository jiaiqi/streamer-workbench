## 1. 不可违反的铁律（AGENTS.md 不可妥协）

1. **`.archive/` 目录是只读归档** — 不得修改/删除/移动
2. **`core/` 禁止 import 任何 UI/服务器框架**（FastAPI / Electron / React / PySide6 均不可在此出现）
3. **金标准 16/16 diff=0 是回归死线** — 禁止用新引擎自举覆盖旧基线；金标准在 `tests/golden/`，独立预言机在 `.archive/design-docs/歌单-排版一/build_playlist.py`
4. **`Song.pinned` 不新增** — 主推 Preset 手动集合 / 最近学会 / 点歌热度规则
5. **`grid-wrap` 固定 2 页兼容模式**（ADR-002）— 新布局用 `pages=auto`；去魔数不改变旧金标准输出
6. **Palette v1 只包含 5 个颜色角色**（text/label/pill/line/mist）+ font_roles（title/label/song/note）— 不把 UI token 混入海报 Palette
7. **Anchors/subjects 使用 0–1 归一化坐标** — 像素输入仅作为兼容层
8. **`halo` 和 `vinyl-rings` 已统一为 `subject-orbit`**，不重复实现
9. **三套新布局各走独立数据通道**：`live-set` → `LiveSessionSnapshot` / `learning-report` → `LearningReportSnapshot` — 不与 `grid-wrap` / `magazine-flow` 共享 `SongLibrary` 路径
10. **编辑器（R7）只在 3 套新布局上线并被真实使用后启动** — 不提前造完整图片编辑器
11. **R8 弹唱播放器不与 R0-R7 路径共用** — PlayView 走 `core/player/`，音频本地优先避免在线版权，chordpro 曲谱优先于 tab_files 图片
12. **`design/archive/` 中的文档已退役** — 只允许追溯历史，不得据此判断当前状态或执行顺序；当前真相以主规格、路线图、数据路线图和 ADR 为准

## 6. 已知技术坑（避坑清单）

### 6.1 路径/导入
- `data/settings.json` 在 worktree 里需从主目录 `cp`
- `ui/node_modules` 和 `electron/node_modules` 在 worktree 里 symlink 到主目录
- worktree 必须显式 cd 到主项目（老 detached HEAD worktree 仍在 cwd 干扰）

### 6.2 后端
- `api_error_response` 导入路径是 `server.api.handlers` 而非 `server.api.errors`
- 端点路径冲突：`/api/posters/compatibility` 被 `/api/posters/{poster_id}` 路由匹配 → 改用 `/api/compatibility` 前缀
- mode="test" + TestClient：必须设 `mode="test"` + `host="127.0.0.1"` + `allowed_origins=("http://localhost", "http://127.0.0.1")`，否则 403
- 多轮 stable sort：(0,0,rev_ts,id) + reverse=True 复合语义非直觉

### 6.3 前端 / vitest
- `toBeInTheDocument` 找不到（jest-dom 未 setup）→ 改用 `toBeNull` / `toBeTruthy`
- JSX 泛型陷阱：`useIntersection<HTMLDivElement>({...})` 在 tsx 中 `<T>` 被解析为 JSX — 测试里不要传泛型
- DataTransfer jsdom 不实现：测试用 stub `{getData, setData, effectAllowed, dropEffect}`
- `navigator.clipboard` 浏览器只读 — vitest 用 `vi.spyOn` 替代 `Object.defineProperty`
- 重复 class 定义（Pydantic 重复 append 出现 3 次）— 用 `awk` 截断 + 重新 append
- React18+Portal+Toast 偶发时序不稳 — 部分测试用 `waitFor` 妥协

### 6.4 平台
- Windows 控制台 GBK → 统一入口 `python tools/run_tests.py` 自动注入 `PYTHONUTF8`
- Windows Git Bash `grep` 中文路径 bug → 用 `ls -R` 代替 `find`
- macOS `webContents.share` API 不存在 → osascript 桥接
- macOS 自签证书拦截影响 /api/metadata/* 端到端
- macOS arm64 only（用户授权）

### 6.5 Engine / 渲染
- 缩略图 `object-cover` → 必须 `object-cover object-bottom`（背景装饰集中底部）
- 字体缓存：`@lru_cache` 32 条目
- 主题背景图命名不统一：6 套用 `bg1.png`，海洋柔光独用 `background-1.png`
